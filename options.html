Lista manual de domínios

Um domínio por linha. Pode colar o URL: o hostname é extraído. Ordem: bloquear primeiro estes, depois a lista +18 até ao limite do Chrome (5000 regras no total em conjunto). Se passar, os restantes ficam de fora; veja a mensagem abaixo após guardar.

Lista +18 (remota)

Formato aceite: ficheiro um domínio por linha (e comentários com #), ficheiro estilo hosts (ex.: 0.0.0.0 sitio.mau) ou JSON com array de domínios ou com domains / hosts / block. Listas de terceiros podem ter falsos positivos ou negativos.

Regras aplicadas na última reconstrução (aprox.): manual 0, +18 0 (teto: 5000).
